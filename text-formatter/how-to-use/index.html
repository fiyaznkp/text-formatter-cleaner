How to Use Text Formatter

Learn how to format, find, clean and organize text with the tools available in Text Formatter. This guide walks through the main sections and explains when to use each feature.

Start by entering or pasting your text into the editor on the Home page. Then choose the tool that matches your task. Review your result before copying or downloading it.

Getting started

The basic workflow is the same for most tasks.

1

Enter your text

Open the home page and type into the editor or paste text from another application.

2

Choose a tool

Select Text Formatter, Find & Replace, Clean Text or Format Lists from the tool navigation.

3

Apply an action

Choose the operation you need. Some tools let you set options before applying a change.

4

Review and export

Check the updated text, make further edits if needed, then copy the result or download it as a TXT file.

Use Text Formatter to change capitalization or make simple text adjustments.

2. Find, Remove & Replace

Use this section to locate matching words or phrases, move between matches, remove them or replace them with new text.

Find a word or phrase

Enter a word, phrase or sentence and select Find matches. Use Previous and Next to move through the matches.

Remove matches

Select Remove from my text to delete the matching occurrences from the editor. Review the result to make sure the removal has not affected the meaning.

Replace text

Enter the text to find and the replacement wording, then select Replace in my text to update the matching occurrences.

Review each change

Use Clear to reset the Find and Replace fields when you want to start a new search.

3. Clean Text

Use Clean Text to filter characters, tidy lines, remove duplicates or extract specific information from your text.

Keep selected content

Keep only numbers, only words, letters and numbers, or numbers with decimals. These options remove other content that does not match the selected type.

Remove unwanted content

Remove numbers, special characters or decimal points when you need a simpler text result.

Clean spacing and lines

Trim spaces at the beginning and end of lines, replace tabs with spaces, remove duplicate words, remove duplicate lines or remove empty lines.

Extract information

Extract numbers, email addresses or URLs from a larger block of text. The extracted items can then be reviewed and reused separately.

The Clean Text section includes frequently used tools and additional options under More cleaning tools. Check the result after each operation, especially when removing or filtering content.

4. Format Lists

Use Format Lists to turn plain lines into a clear list or remove bullet markers from existing text.

Remove bullets

Remove existing bullet markers from the beginning of list lines to return the content to plain text.

Add bullets

Add bullet markers to separate lines to create a bulleted list.

Add numbers

Add sequential numbering to separate lines to create a numbered list.

5. Text statistics and editing controls

The editor provides useful information and controls while you work.

Text statistics

View the word count, character count, sentence count, line count and estimated reading time. The statistics update as you edit your text.

Copy and download

Select Copy to copy the current editor text to your clipboard, or use Download .TXT to save it as a text file.

Clear

Select Clear when you want to remove the current text from the editor. Make sure you no longer need the text before clearing it.

Undo and redo

Use Undo to reverse a recent change and Redo to restore a change that was undone.

Load sample

Select Load sample to place example content in the editor and try the available formatting and cleaning tools.

Light and dark mode

Use the theme button in the top navigation to switch between light and dark appearance. Your selected theme is saved in your browser for future visits.

Tips for better results

Enter the complete text first. Paste the block of text into the editor before choosing a formatting or cleaning operation.
Choose the right tool. Use Find & Replace for targeted wording changes, Clean Text for removing or extracting content, and Format Lists for organizing lines.
Review the result. Check punctuation, spacing and meaning after applying an operation, especially when removing or replacing content.
Use Undo if needed. If a conversion or cleanup produces an unwanted result, use Undo before trying another option.
