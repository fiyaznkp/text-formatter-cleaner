Text formatting examples

See how each formatting and cleaning option changes text.

Uppercase

Converts all letters to uppercase.

Before: hello world
After: HELLO WORLD

Lowercase

Converts all letters to lowercase.

Before: HELLO WORLD
After: hello world

Sentence Case

Converts text to sentence-style capitalization.

Before: hello WORLD. this is a TEST.
After: Hello world. This is a test.

Capitalized Case

Capitalizes the first letter of each word.

Before: hello world from text formatter
After: Hello World From Text Formatter

Title Case

Formats text using title-style capitalization.

Before: the lord of the rings
After: The Lord of the Rings

Remove extra spaces

Reduces repeated spaces within lines and trims surrounding spaces.

Remove commas

Removes comma characters from the current text.

You can convert text to Sentence Case, lowercase, UPPERCASE, Capitalized Case or Title Case.

Does the tool count words and characters?

Yes. It displays word, character and sentence counts, plus estimated reading time.

Can I use the formatter on a phone?

About the reading-time estimate

Reading time is an estimate based on a typical reading speed. Your actual reading time may vary depending on the text and how quickly you read.
