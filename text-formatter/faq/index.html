Frequently Asked Questions

Find answers to common questions about Text Formatter, including how to use the text formatting, find and replace, cleaning, list formatting, and editing tools.

General Questions

A few basics about the tool and how to get started.

What is Text Formatter?
Text Formatter is a free online tool for changing text case, finding and replacing words or phrases, cleaning content, formatting lists, and checking text statistics. You can access the tools from the Home page.
Is Text Formatter free to use?
Yes. The main text formatting and cleaning tools are available on the website without requiring an account.
Do I need to install software or create an account?
No. You can use the main tools in a modern web browser without installing a separate application or creating an account.
How do I get started?
Open the Home page, enter or paste your text into the editor, and choose the tool that matches your task. You can also read the How to Use guide for step-by-step instructions.

Text Formatting

Questions about changing capitalization and preparing text.

Which text case options are available?
The Text Formatter includes Sentence Case, lowercase, UPPERCASE, Capitalized Case, and Title Case.
What is the difference between Capitalized Case and Title Case?
Capitalized Case makes the first letter of each word uppercase. Title Case applies title-style capitalization rules, which may keep some short connecting words lowercase.
Will formatting change numbers or punctuation?
The case-conversion options primarily change alphabetic characters. Numbers and punctuation are generally retained, but review the result before using it elsewhere.

Find, Remove & Replace

Find matching text and make targeted changes in the editor.

Can I find a specific word or phrase?
Yes. Enter the word or phrase in the Find tool and select Find matches. Use Previous and Next to move between the matching occurrences.
How do I remove matching text?
Enter the word or phrase in the Find tool, select Find matches if you want to review the occurrences, and then select Remove from my text to remove matching occurrences from the editor. Review the updated text afterwards.
How do I replace a word or phrase?
Enter the word or phrase in the Find field and the new wording in the Replace it with field. Select Replace in my text to update the matching occurrences in the editor.

Clean Text

Use these tools to filter characters, tidy lines, remove duplicates, or extract information.

What can I do with Clean Text?
You can keep only numbers, words, letters and numbers, or numbers with decimals; remove numbers, special characters, or decimal points; trim line spaces; replace tabs with spaces; remove duplicate words, duplicate lines, or empty lines; and extract numbers, email addresses, or URLs.
Can I extract email addresses or URLs from text?
Yes. Use the extraction options to find email addresses or URLs in the text. You can also extract numbers from a larger block of content.
Can I remove duplicate lines or words?
Yes. Clean Text includes separate options for removing duplicate words and duplicate lines. There is also an option to remove empty lines.

Format Lists

Turn separate lines into a list or remove existing list markers.

Can I add bullets to plain text?
Yes. Use Add bullets to add bullet markers to separate lines in your text.
Can I create a numbered list?
Yes. Use Add numbers to add sequential numbering to separate lines.
Can I remove existing bullets?
Yes. Use Remove bullets to remove bullet markers from the beginning of list lines.

Editor, Statistics & Theme

More information about the editor controls and display settings.

Which text statistics are available?
The editor displays word count, character count, sentence count, line count, and estimated reading time. These statistics update as you edit your text.
Can I undo or redo an action?
Yes. Use Undo to reverse a recent change and Redo to restore a change that was undone.
What does the Clear button do?
The Clear button below the editor removes the current text from the text box. If you only want to reset a search, use the separate Clear button in the Find, Remove & Replace section to clear its search fields.
Can I copy or download my text?
Yes. Use Copy to copy the current editor text, or Download .TXT to save it as a plain text file.
Can I switch between dark and light mode?
Yes. Use the theme button in the top navigation to switch between dark and light mode. Your selected theme is saved in your browser using the shared site preference, so pages using the same setting can keep the same appearance.

Privacy & Data

Understand how the main tool works and where to find more information.

Is my text uploaded to a server?
The main formatting operations are designed to run directly in your browser. The website also uses analytics and browser storage for certain site preferences. See the Privacy Policy for more information about website data practices.
Does the website use analytics?
The website includes Google Analytics to understand general website usage and help improve the service. More information is available in the Privacy Policy.
Where can I report an issue or send feedback?
Visit the Contact page to send a question, report an issue, or share a suggestion.
